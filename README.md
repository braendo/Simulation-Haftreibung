# Physik-Simulationen – 8. Klasse Gymnasium

Interaktive Browser-Simulationen für den Physikunterricht (Klasse 8, Gymnasium).  
Jede Simulation ist eine **einzelne, selbstständige HTML-Datei** – kein Framework, 
kein CDN, keine externen Abhängigkeiten. Einfach herunterladen und im Browser öffnen.

## Themen (Mechanik)
- Haftreibung & Gleitreibung (schiefe Ebene + waagrechte Ebene)
- Schiefe Ebene (Kräftezerlegung)
- weitere Simulationen in Entwicklung …

## Merkmale
- **Canvas-Animation** mit `requestAnimationFrame` (physikalisch korrekte Zeitschritte)
- **Zwei Simulationsmodi** je Thema (z. B. schiefe Ebene / waagrechte Ebene)
- **Vektorgrafik** mit korrekt indizierten Größen (F⃗_G, F⃗_N, F⃗_HR …)
- **Erklärungsreiter** mit Unterrichtsinhalten (Hefteintrag)
- Responsive, funktioniert auf Schüler-Tablets
- Deutsch · g = 9,81 m/s² · Dezimalkomma

## Verwendung
Datei herunterladen → Doppelklick → fertig.  
Keine Installation, kein Server notwendig.

## Zielgruppe
Lehrkräfte und Schüler:innen der **8. Klasse Gymnasium** (Bayern / D-A-CH).
